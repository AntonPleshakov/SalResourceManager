Sal Resources Manager

Telegram-бот для управления игровыми кланами, участниками и ресурсами.

Интеграция с Google

По явной команде администратора бот экспортирует данные выбранного клана в закрытую Google Таблицу.

  • Google Sheets используется для записи и обновления отчёта.
  • Google Drive используется для создания таблиц в выделенной папке и управления доступом к ним.
  • Приложение не использует данные Google для рекламы и не продаёт их.

Доступ

Приложение предназначено для администратора и известных ему участников игровых кланов. Авторизация Google выполняется владельцем аккаунта через стандартную страницу согласия Google.
